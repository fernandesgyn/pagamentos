# Sistema de Gestão de Liquidação e Pagamentos

Aplicação para gerenciar o fluxo administrativo e financeiro desde a obrigação contratual até inspeção, programação de pagamento, liquidação, CMDF e pagamento.

Arquitetura espelhada do projeto `fernandesgyn/licitacoes`: PHP puro 8.2+, MySQL 8+, MVC explícito e interface AdminLTE.

> O schema consolidado está em `database/schema.sql`. O projeto é instalado a partir de banco limpo, sem migrations incrementais.
